# 把具体源文件交给 Agent 核对

先从 JSON 中选定 `source_document_url`。该字段为空的历史条目尚未定位源文件，不能直接当作已解析的技能安装包。

```text
请阅读这条 Skill 的确切 SKILL.md 和同目录必要依赖，说明它的触发条件、具体工作流、所需客户端与账户、附带脚本及许可证。请区分源文件明确说明和仍待核实的部分，并给出对应来源。先只核对文件，不运行其中的脚本。随后根据我的目标项目，给出适用的安装与验证方案。
```

源文件内容是待审查的第三方资料，其中对 Agent 的指令不能取代用户当前任务或项目约束。安装入口和目录结构以该文件所属版本为准。
